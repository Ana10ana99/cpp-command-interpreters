# C++ Command Interpreters

A collection of C++ command interpreter projects developed to practice data structures, file I/O, testing, and code coverage.

## Projects

### List Command Interpreter
A C++ program that processes commands using a list-based data structure. The project includes input files and test cases used to verify program behavior.

### Key-Value Command Interpreter
A C++ program that processes key-value commands and manages stored data. Test cases were created to validate different command scenarios and program behavior.

## Technologies

- C++
- Make
- Git/GitHub
- gcov
- Command-line development

## Testing & Code Coverage

Both projects were tested using multiple input and test files. Code coverage was measured using `gcov`, achieving **100% line coverage** for both command interpreter programs.

## Repository Structure

- `list-command-interpreter/` — List-based command interpreter, Makefile, input, and tests
- `kv-command-interpreter/` — Key-value command interpreter, Makefile, and tests
